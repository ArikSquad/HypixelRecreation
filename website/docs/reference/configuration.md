# Configuration Reference

This page documents all configuration files and their options.

## config.yml

The main configuration file shared by all servers and services.

**Location**: `configuration/config.yml`

```yml
host-name: 0.0.0.0
mongodb: mongodb://localhost
redis-uri: redis://localhost:6379
velocity-secret: your-forwarding-secret-here
require-auth: false
integrations:
    spark: false
    anticheat: false
    via-version: true
    sentry-dsn: ''
limbo:
    host-name: 127.0.0.1
    port: 65535
resource-packs: { }
```

### Fields

| Field             | Required | Description                                  |
|-------------------|----------|----------------------------------------------|
| `host-name`       | Yes      | Address to bind the server to                |
| `mongodb`         | Yes      | MongoDB connection string                    |
| `redis-uri`       | Yes      | Redis connection string                      |
| `velocity-secret` | Yes      | Must match `forwarding.secret` from Velocity |
| `require-auth`    | No       | Require authentication on initial connection |
| `integrations.spark`      | No       | Enable Spark performance monitoring |
| `integrations.anticheat`  | No       | Enable anti-cheat measures          |
| `integrations.via-version`| No       | Support multiple Minecraft versions (may cause issues) |
| `integrations.sentry-dsn` | No       | Sentry error tracking DSN (empty = disabled) |
| `limbo.host-name` / `limbo.port` | No | PicoLimbo connection details   |
| `resource-packs`  | No       | Resource pack server URLs keyed by pack name |

### Docker Configuration

For Docker deployments, use `config.docker.yml`:

```yml
velocity-secret: "docker-secret"
mongodb: "mongodb://mongodb"
redis-uri: "redis://redis:6379"
...
```

Note the hostnames `mongodb` and `redis` match Docker service names.

## velocity.toml

Velocity proxy configuration.

**Location**: `velocity.toml` (proxy directory)

### Key Settings

```toml
# Bind address
bind = "0.0.0.0:25565"

# Online mode (true = premium only, false = cracked)
online-mode = true

# Player forwarding mode (must be "modern")
player-info-forwarding-mode = "modern"

# Max players
show-max-players = 500

# MOTD
motd = "<green>Hypixel</green>"
```

### Server Registration

Servers register dynamically via Redis, so you don't need to manually configure server entries.

## PicoLimbo server.yml

Configuration for the limbo server.

**Location**: `server.toml` (PicoLimbo directory)

### Key Settings

```toml
[forwarding]
method = "MODERN"
secret = "${FORWARDING_SECRET}"
```

:::alert warning
The `secret` must match your Velocity forwarding secret exactly.
:::

## Environment Variables

Some settings can be overridden via environment variables:

| Variable      | Description                 |
|---------------|-----------------------------|
| `MONGODB_URI` | Override MongoDB connection |
| `REDIS_URI`   | Override Redis connection   |
| `API_PORT`    | Override API service port   |

## Database Collections

MongoDB collections created automatically:

| Collection              | Purpose                  |
|-------------------------|--------------------------|
| `profiles`              | Player profiles and data |
| `users`                 | User accounts            |
| `authentication`        | Login sessions           |
| `active-auctions`       | Active auctions          |
| `inactive-auctions`     | Completed auctions       |
| `bazaarOrders`          | Bazaar buy/sell orders   |
| `pendingTransactions`   | Bazaar pending transactions |
| `tracked-items`         | Item tracking            |
| `friend-data`           | Friend lists             |
| `pending-friend-requests` | Pending friend requests |
| `elections`             | Election definitions     |
| `election-votes`        | Cast votes               |
| `election-tallies`      | Vote tallies             |
| `guilds`                | Guild definitions        |
| `player-guilds`         | Player guild membership  |
| `punishments`           | Punishment records       |
| `replays`               | Replay metadata          |
| `replay_data`           | Recorded replay data     |
| `replay_maps`           | Uploaded replay maps     |
| `store_purchases`       | Store checkout state     |
| `stripe_events`         | Stripe webhook records   |
| `store-player-entitlements` | Per-player store awards |
| `api-key`               | API keys                 |
| `api-admin`             | Admin sessions           |
